Topic 15

Text

This chapter teaches you how to manipulate text using CSS properties. You can set following text properties of an element −

PropertyDescription
coloris used to set the color of a text.
directionis used to set the text direction.
letter-spacingis used to add or subtract space between the letters that make up a word.
word-spacingis used to add or subtract space between the words of a sentence.
text-indentis used to indent the text of a paragraph.
text-alignis used to align the text of a document.
text-decorationis used to underline, overline, and strikethrough text.
text-transformis used to capitalize text or convert text to uppercase or lowercase letters.
white-spaceis used to control the flow and formatting of text.
text-shadowis used to set the text shadow around a text.

Set the Text Color

The following example demonstrates how to set the text color. Possible value could be any color name in any valid format.

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <p style="color:red;">
      This text will be written in red.
      </p>
   </body>
</html>

Practical Examples

Styling an article heading with capitalization and a paragraph with comfortable reading spacing:

CSS
<style>
.article-title {
   text-align: center;
   text-transform: uppercase;
   letter-spacing: 2px;
}

.article-body {
   /* Increases space between lines for readability */
   line-height: 1.6;
   color: #333333;
}
</style>

<h1 class="article-title">Breaking News</h1>
<p class="article-body">This is an article body with beautifully spaced and aligned text, demonstrating good typographic readability.</p>

Common Mistakes

  • Using text-align: justify on web − Unlike print, web browsers don't hyphenate well automatically. Justified text creates ugly, uneven "rivers of whitespace" between words, hurting readability.
  • Ignoring line-height − Leaving line-height at its default makes multi-line paragraphs feel cramped and extremely hard to read.
  • Using underlines for non-links − Using text-decoration: underline for emphasis on normal text. Users have been trained for decades that underlined text is clickable. This causes immense UX confusion.
  • Typing ALL CAPS in HTML − Writing <h1>WELCOME</h1> in HTML. Screen readers might read this out letter-by-letter. Write normal case in HTML and use text-transform: uppercase; in CSS.

Best Practices

  • Set a comfortable Line Height − Always set paragraph line-height between 1.4 and 1.6 to give the text room to breathe.
  • Keep Line Lengths Optimal − For maximum readability, limit your paragraph widths to about 60-75 characters per line (e.g., using max-width: 65ch;).
  • Use Text-Transform for styling − Keep your source HTML semantically accurate (Sentence case) and use text-transform to visually alter case.
  • Optimize for readability − Sufficient line-height (usually 1.5 or higher) and adequate font-size significantly improve readability for users with dyslexia or low vision.

Interview Questions

Q: What is the difference between text-align and justify-content?

A: text-align is used to align inline content (like text) inside a block container. justify-content is a Flexbox/Grid property used to align entire elements within a layout.

Q: How do you remove the default underline from a link?

A: By applying text-decoration: none; to the <a> tag.

Q: What property modifies the spacing between individual letters?

A: The letter-spacing property.

Q: Why is line-height usually written as a unitless number (e.g., 1.5) rather than pixels (24px)?

A: A unitless number acts as a multiplier based on the element's font size. If the font size scales up, the line height scales proportionately. Fixed pixels do not.

Summary

While the fonts properties control what typeface is drawn, the text properties control how that type is arranged, spaced, and formatted. Mastering properties like line-height, text-align, and text-transform is the key to creating highly legible and professional-looking content on the web.

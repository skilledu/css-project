Measurement Units — Absolute

CSS supports absolute measurement units such as inches, centimeters, points, pixels, etc. These values represent a physical measurement and are generally considered to always be the same size.

Absolute Units

Unit Description Example
cm Defines a measurement in centimeters. div { margin-bottom: 2cm; }
in Defines a measurement in inches. p { word-spacing: .15in; }
mm Defines a measurement in millimeters. p { word-spacing: 15mm; }
pc Defines a measurement in picas. A pica is equivalent to 12 points; 6 picas per inch. p { font-size: 20pc; }
pt Defines a measurement in points. 1 point = 1/72nd of an inch. body { font-size: 18pt; }
px Defines a measurement in screen pixels. p { padding: 25px; }

Code Examples

Pixels (px)

CSS 
p {
   padding: 25px;
   font-size: 18px;
}

Points (pt)

CSS 
body {
   font-size: 18pt;
}

   margin-bottom: 2cm;

   word-spacing: 15mm;

Practical Examples

Using absolute units for precise print styling or tiny decorative borders where scaling isn't desired:

CSS
<!DOCTYPE html>
<html>
<head>
<style>
@media print {
   /* Print layouts often use pt and in */
   .print-text {
      font-size: 12pt;
      margin: 1in;
   }
}

.hairline-border {
   /* A 1px border is common because we don't want it scaling */
   border-bottom: 1px solid #333;
   padding-bottom: 10px;
   margin-bottom: 15px;
}
</style>
</head>
<body>

<div class="hairline-border">
  This text has a 1px solid border below it that will never scale up or down.
</div>

<div class="print-text">
  If you were to print this page, this text would have a 1 inch margin and a 12pt font size.
</div>

</body>
</html>

Common Mistakes

  • Using px for font sizes − Absolute units like px ignore the user's browser accessibility settings. If a user sets their default browser font to be large, a hardcoded 16px font will remain stubbornly small.
  • Using physical units on screens − Using cm or in for screen layouts. Screens have varying pixel densities, so 1 inch on a low-res monitor might appear wildly different in size on a high-res Retina screen.

Best Practices

  • Limit absolute units to tiny details − Use px only for borders, subtle box-shadows, or extremely small spacing tweaks where responsiveness is not a factor.
  • Use pt and in for Print Styles − If you are writing a print stylesheet (using @media print), absolute physical units like points and inches are perfectly acceptable because they translate accurately to paper.

Interview Questions

Q: What is the primary drawback of using px for typography?

A: Pixels are absolute and do not scale dynamically with the user's browser accessibility preferences, which can make text unreadable for visually impaired users.

Q: Is 1 pixel (px) in CSS always exactly one hardware pixel on the monitor?

A: No. A CSS pixel is a logical unit. On high-density screens (like Apple's Retina displays), one CSS pixel might actually map to 4 (2x2) or even 9 (3x3) physical hardware pixels.

Q: When would you ever use cm or in in CSS?

A: Almost exclusively for print stylesheets where the physical output dimensions are known and guaranteed.

Summary

Absolute units represent a fixed physical or logical measurement. While px remains incredibly popular for small UI details, relying on absolute units for layout dimensions and typography makes websites rigid and inaccessible. Modern CSS development favors relative units for layout and typography, reserving absolute units for print media and minor pixel-perfect decorative borders.

Topic 45

Text

The following are the most commonly used text properties in CSS3:

Property Description
text-align-last Used to align the last line of the text
text-emphasis Used to emphasize text and color
text-overflow Used to determine how overflowed content that is not displayed is signaled to users
word-break Used to break the line based on word
word-wrap Used to break the line and wrap onto the next line

Text-overflow

The text-overflow property determines how overflowed content that is not displayed is signaled to users. The sample example of text overflow is shown as follows −

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         p.text1 {
            white-space: nowrap;
            width: 200px;
            border: 1px solid #000000;
            overflow: hidden;
            text-overflow: clip;
         }
         p.text2 {
            white-space: nowrap;
            width: 200px;
            border: 1px solid #000000;
            overflow: hidden;
            text-overflow: ellipsis;
         }
      </style>
   </head>
   <body>
      <b>Original Text:</b>
<p>This is an Hello World used to demonstrate CSS styling. It provides enough content to see how text wrapping, spacing, and other typographic properties affect the layout of your web page.</p>
<b>Text overflow: clip:</b>
<p class="text1">This is an Hello World used to demonstrate CSS styling. It provides enough content to see how text wrapping, spacing, and other typographic properties affect the layout of your web page.</p>
<b>Text overflow: ellipsis:</b>
<p class="text2">This is an Hello World used to demonstrate CSS styling. It provides enough content to see how text wrapping, spacing, and other typographic properties affect the layout of your web page.</p>
   </body>
</html>

CSS3 Word Breaking

The word-break property is used to break the line. The following code shows a sample code of word breaking:

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         p.text1 {
            width: 140px;
            border: 1px solid #000000;
            word-break: keep-all;
         }
         p.text2 {
            width: 140px;
            border: 1px solid #000000;
            word-break: break-all;
         }
      </style>
   </head>
   <body>
      <b>Line break at hyphens:</b>
<p class="text1">This is an Hello World used to demonstrate CSS styling. It provides enough content to see how text wrapping, spacing, and other typographic properties affect the layout of your web page.</p>
<b>Line break at any character:</b>
<p class="text2">This is an Hello World used to demonstrate CSS styling. It provides enough content to see how text wrapping, spacing, and other typographic properties affect the layout of your web page.</p>
   </body>
</html>

CSS word wrapping

Word wrapping is used to break the line and wrap onto the next line. The following code shows a sample syntax:

HTML/CSS 
p {
   word-wrap: break-word;
}

Practical Examples

The standard "Holy Trinity" of CSS properties required to gracefully truncate a long username with an ellipsis (...):

CSS
<style>
.user-profile-name {
   width: 200px; /* Constrain the width */

   /* 1. Prevent text from wrapping to the next line */
   white-space: nowrap;
   /* 2. Hide whatever bleeds outside the box */
   overflow: hidden;
   /* 3. Add the "..." effect at the cutoff point */
   text-overflow: ellipsis;
}
</style>

<div class="user-profile-name" style="background:#eee; padding:10px; width:150px;">JohnDoeWithAVeryLongNameThatWillBeTruncated</div>

Common Mistakes

  • Using text-overflow alone − Applying text-overflow: ellipsis; does absolutely nothing by itself. It MUST be paired with white-space: nowrap; and overflow: hidden; on a block-level element with a defined width.
  • Using word-break: break-all on normal paragraphs − This forces words to break exactly at the container edge, completely disregarding syllables or hyphens (e.g., breaking the word "Hello" into "He" and "llo"). This ruins readability.
  • Applying truncation to multi-line text − The standard text-overflow: ellipsis only works for single-line text. Multi-line truncation requires complex Flexbox line-clamping techniques (-webkit-line-clamp).

Best Practices

  • Understand Vendor Prefixes − Some newer or experimental CSS properties need a browser-specific prefix (like -webkit- or -moz-) to work in certain browsers before becoming fully standardized. For instance, the -webkit-line-clamp property specifically needs display: -webkit-box and -webkit-box-orient: vertical alongside it to work.
  • Use overflow-wrap: break-word globally − Add this to your base CSS reset. It ensures that if a user pastes a massive, unbroken 100-character URL into a comment, it will wrap gracefully instead of breaking the entire page layout.
  • Reserve ellipsis for UI constraints − Use the ellipsis truncation pattern strictly for tight UI components (like navigation bars, data tables, or card titles). Avoid truncating actual paragraph content.

Interview Questions

Q: What three CSS properties are required to create a single-line text ellipsis (...) effect?

A: white-space: nowrap, overflow: hidden, and text-overflow: ellipsis.

Q: What is the difference between word-break: break-all and overflow-wrap: break-word?

A: break-all aggressively snaps words exactly at the edge of the box regardless of spacing. break-word is smarter; it will only snap and break a word if the single word is so long that it cannot fit on its own line (like a long URL).

Q: How do you prevent a specific line of text from wrapping?

A: By applying white-space: nowrap;.

Summary

Advanced text properties are essential for defensive CSS. You cannot control what data users will input into your layout. Mastering text-overflow: ellipsis for single-line UI elements and overflow-wrap: break-word for user-generated content ensures your layout will never blow out and horizontally scroll, no matter how long the text is.

CSS Flexbox

Introduction to Flexbox

The Flexible Box Layout Module (Flexbox) makes it easier to design flexible responsive layout structure without using float or positioning.

Before Flexbox, layouts were built using block, inline, table, or float. Flexbox solves the problem of aligning items in 1-Dimensional layouts (either a row or a column), especially when the size of the items is unknown or dynamic.

You initiate a flex formatting context by setting display: flex (block-level) or display: inline-flex (inline-level).

Main Axis vs Cross Axis: Flexbox relies on two axes. If flex-direction is row, the Main Axis runs left-to-right, and the Cross Axis runs top-to-bottom. Alignment properties apply relative to these axes.

CSS
.container {
   display: flex;
}

Flex Container Properties

The following properties apply to the flex container (the parent element that holds the flex items).

flex-direction

Defines the direction flex items are placed in the flex container (the Main Axis).

Value Description
row (default) Left to right.
row-reverse Right to left.
column Top to bottom.
column-reverse Bottom to top.
CSS
.container {
   display: flex;
   flex-direction: row-reverse;
}

flex-wrap

Specifies whether the flex items should wrap or not if there isn't enough room.

Value Description
nowrap (default) All items fit on one line.
wrap Items wrap onto multiple lines.
wrap-reverse Items wrap in reverse order.
CSS
.container {
   display: flex;
   flex-wrap: wrap;
}

flex-flow

A shorthand for both flex-direction and flex-wrap.

CSS
.container {
   flex-flow: row wrap;
}

justify-content

Aligns items along the Main Axis.

Value Description
flex-start (default) Items packed at start.
flex-end Items packed at end.
center Items packed at center.
space-between Items evenly distributed; first line at start, last at end.
space-around Items evenly distributed with equal space around them.
space-evenly Items evenly distributed with equal space between them and edges.
CSS
.container {
   display: flex;
   justify-content: space-between;
}

align-items

Aligns items along the Cross Axis.

Value Description
stretch (default) Items stretch to fill the container height.
flex-start Items placed at the start of cross axis.
flex-end Items placed at the end of cross axis.
center Items placed in the middle.
baseline Items aligned by their text baseline.
CSS
.container {
   display: flex;
   align-items: center;
}

align-content

Aligns flex lines when there is extra space in the cross-axis. (Only applies if flex-wrap: wrap is set and there are multiple lines).

CSS
.container {
   display: flex;
   flex-wrap: wrap;
   align-content: space-around;
}

gap / row-gap / column-gap

Defines the space between flex items.

CSS
.container {
   display: flex;
   gap: 20px; /* 20px gap between all items */
}

Flex Item Properties

The following properties apply directly to the individual flex items (the child elements).

order

Controls the order in which items appear. Default is 0.

CSS
.item-first {
   order: -1;
}

flex-grow

Defines how much a flex item will grow relative to the rest of the flex items. Default is 0 (don't grow).

CSS
.item {
   flex-grow: 1; /* Take up remaining space */
}

flex-shrink

Defines how much an item will shrink relative to the rest. Default is 1.

CSS
.item {
   flex-shrink: 0; /* Do not shrink */
}

flex-basis

Specifies the initial main size of a flex item before free space is distributed.

CSS
.item {
   flex-basis: 200px;
}

flex (Shorthand)

Shorthand for flex-grow, flex-shrink, and flex-basis.

CSS
.item {
   flex: 1 1 200px;
   /* Commonly used as flex: 1 to make items grow evenly */
}

align-self

Overrides the container's align-items value for this specific item.

CSS
.item {
   align-self: flex-end;
}

Responsive Example

A common navigation bar layout that collapses to a column on mobile:

CSS
.nav {
   display: flex;
   flex-direction: row;
   justify-content: space-between;
}

@media (max-width: 600px) {
   .nav {
      flex-direction: column;
      align-items: center;
   }
}

Practical Examples

Here is a complete, working example of a Flexbox layout.

HTML/CSS
<!DOCTYPE html>
<html>
   <head>
      <style>
         .flex-container {
            display: flex;
            justify-content: space-around;
            background-color: DodgerBlue;
            padding: 10px;
         }
         .flex-container > div {
            background-color: #f1f1f1;
            width: 100px;
            margin: 10px;
            text-align: center;
            line-height: 75px;
            font-size: 30px;
         }
      </style>
   </head>
   <body>
      <h1>Flexbox Example</h1>
      <div class="flex-container">
         <div>1</div>
         <div>2</div>
         <div>3</div>
      </div>
   </body>
</html>

Common Mistakes

  • Forgetting to set height: align-items: center won't vertically center an item if the flex container doesn't have a defined height.
  • Misunderstanding justify vs align: Remember: justify-content works on the Main Axis, align-items works on the Cross Axis. If you change flex-direction: column, they swap visual directions!

Best Practices

  • Use Shorthand: Prefer using the flex shorthand on flex items instead of writing grow, shrink, and basis separately.
  • Use Gap: Instead of putting margins on flex items (and fighting with the outer margins), use the gap property on the flex container.

Interview Questions

  • What is the difference between align-items and align-content?
    align-items aligns individual items on the cross axis. align-content aligns multiple lines of items when they wrap.
  • What does flex: 1 mean?
    It is shorthand for flex: 1 1 0%. It tells the item to grow to fill space, shrink if needed, and start with a basis of 0.

Summary

Flexbox is a 1-dimensional layout model that excels at distributing space and aligning items in a single row or column. By understanding the main and cross axes, and the separation between container properties and item properties, you can build complex, responsive layouts with minimal code.

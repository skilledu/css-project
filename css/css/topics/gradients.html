Gradients

What is Gradients?

Gradients display the combination of two or more colors as shown below:

Types of gradients

Type Description
Linear Gradients down/up/left/right/diagonally
Radial Gradients defined by their center

Linear gradients

Linear gradients are used to arrange two or more colors in linear formats like top to bottom.

Top to bottom

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         #grad1 {
            height: 100px;
            background: -webkit-linear-gradient(pink,green);
            background: -o-linear-gradient(pink,green);
            background: -moz-linear-gradient(pink,green);
            background: linear-gradient(pink,green);
         }
      </style>
   </head>
   <body>
      <div id="grad1"></div>
   </body>
</html>

Practical Examples

A vibrant, modern button with an angled linear gradient, and a striped progress bar utilizing a repeating linear gradient:

CSS
<style>
/* Standard Angled Gradient */
.btn-gradient {
   background-image: linear-gradient(135deg, #f093fb 0%, #f5576c 100%);
   color: white;
}

/* Striped Progress Bar Effect */
.progress-bar {
   background-image: repeating-linear-gradient(
      45deg,
      #3b82f6,
      #3b82f6 10px,
      #2563eb 10px,
      #2563eb 20px
   );
}
</style>

<button class="btn-gradient" style="padding:15px 30px; border:none; border-radius:5px; margin-bottom:20px; color:white;">Cool Button</button>
<div class="progress-bar" style="height:30px; width:100%; border-radius:15px;"></div>

Common Mistakes

  • Treating gradients as a color − Gradients cannot be applied to the background-color property. They are generated by the browser as an image, and must be applied to background-image (or the background shorthand).
  • Failing to provide a solid fallback − Older environments or email clients strip out gradients. Always declare a solid background-color right before your gradient rule so the layout survives.
  • The "Gray Dead Zone" in Safari − Fading from a solid color to transparent can create an ugly grayish-black artifact in Safari. Best practice is to fade to an invisible version of the same color (e.g., rgba(255,0,0, 1) to rgba(255,0,0, 0)).

Best Practices

  • Use degrees for angles − While to bottom right is easy to read, using degrees (like 135deg) provides far more precision and consistency, especially when syncing design files from Figma.
  • Use Hard Stops for sharp lines − As shown in the progress bar example, if two color stops share the exact same percentage (e.g., red stops at 50%, blue starts at 50%), the gradient creates a razor-sharp dividing line instead of a soft blend.

Interview Questions

Q: Are CSS gradients applied to the background-color or background-image property?

A: background-image. The browser dynamically generates an image from the gradient math.

Q: How do you create a sharp, distinct line between two colors in a gradient instead of a smooth fade?

A: By placing two color stops at the exact same location (e.g., linear-gradient(to right, red 50%, blue 50%)).

Q: What is the difference between a linear and a radial gradient?

A: A linear gradient flows in a straight line from one side to another. A radial gradient radiates outward in a circle or ellipse from a central point.

Summary

CSS Gradients eliminate the need for hefty background images just to create smooth color transitions. By understanding color stops, angles, and the power of repeating gradients (for stripes and patterns), you can build highly performant, visually stunning UI components directly in code.

Topic 29

Measurement Units — Relative

CSS supports relative measurement units such as percentages, ems, rems, and viewport units. These specify a length relative to another length property, making them ideal for responsive design.

Relative Units

Unit Description Example
% Defines a measurement as a percentage relative to another value, typically an enclosing element. p { font-size: 16%; }
em A relative measurement equal to the current font size. If font is 12pt, then 1em = 12pt; 2em = 24pt. p { letter-spacing: 7em; }
ex Defines a measurement relative to a font's x-height — the height of the lowercase letter 'x'. p { line-height: 3ex; }
vh 1% of viewport height. h2 { font-size: 3.0vh; }
vw 1% of viewport width. h1 { font-size: 5.9vw; }
vmin 1vw or 1vh, whichever is smaller. p { font-size: 2vmin; }
rem A relative measurement equal to the root element's font size. p { margin-bottom: 1.5rem; }
vmax 1vw or 1vh, whichever is larger. div { padding: 5vmax; }

Code Examples

Percentage (%)

CSS 
p {
   font-size: 16pt;
   line-height: 125%;
}

em Unit

CSS 
body {
   font-size: 16px;  /* base font */
}
h1 {
   font-size: 2em;   /* 2 x 16px = 32px */
}
p {
   letter-spacing: 0.5em;
}

ex Unit

CSS 
p {
   line-height: 3ex;
}

rem Unit

CSS 
html {
   font-size: 16px; /* Root font */
}
p {
   margin-bottom: 1.5rem; /* 1.5 * 16px = 24px */
}

Viewport Units (vh, vw, vmin, vmax)

CSS 
h2 {
   font-size: 3.0vh;  /* 3% of viewport height */
}
h1 {
   font-size: 5.9vw;  /* 5.9% of viewport width */
}
p {
   font-size: 2vmin;  /* 2% of smaller dimension */
}
div {
   padding: 5vmax;    /* 5% of larger dimension */
}

Practical Examples

A responsive layout pattern using a mix of absolute (px) and relative (rem, %) units for scalability:

CSS
<style>
.container {
   /* Layout uses relative percentages */
   width: 90%;
   max-width: 1200px; /* Absolute cap */
   margin: 0 auto;
}

.card {
   /* Spacing and typography use rem for accessibility */
   padding: 2rem;
   border-radius: 8px; /* px is fine for small decorative touches */
}

.card-title {
   font-size: 1.5rem;
   margin-bottom: 0.5em; /* em is relative to this element's font-size */
}
</style>

<div class="container">
  <div class="responsive-box">I scale based on the root font size and container width!</div>
</div>

Common Mistakes

  • Using px for font sizes − Hardcoding font-size: 16px; ignores the user's browser accessibility settings. If a visually impaired user scales up their default text size, px values will stubbornly remain small.
  • Confusing em and rem − em compounds wildly when nested (a 2em font inside a 2em font becomes 4x the size). rem always relates to the root HTML, making it predictable.
  • Setting fixed heights in px − Setting height: 300px; on a container. If text wraps on mobile, the content will overflow the fixed box. Use min-height instead.

Best Practices

  • Typography & Spacing = REM − Use rem for all font sizes, margins, and paddings so your site scales perfectly with user accessibility preferences.
  • Layout Widths = % or VW − Use percentages or viewport units for container widths to ensure they shrink fluidly on mobile devices.
  • Borders & Small Details = PX − It is perfectly fine to use px for 1px borders or subtle box-shadows where scaling isn't necessary.
  • Accessibility benefits − Relative units like rem and em scale dynamically with user font-size preferences, unlike fixed px units, making them essential for accessible typography.

Interview Questions

Q: What is the difference between rem and em?

A: rem (root em) is relative to the font-size of the root HTML element. em is relative to the font-size of the element's direct parent, which can cause compounding size issues if nested.

Q: What does 100vh mean?

A: It stands for 100 Viewport Height. It means the element will take up exactly 100% of the visible height of the browser window.

Q: Why is using px for font sizes considered bad practice?

A: Because px is an absolute unit. It overrides the user's browser-level font size preferences, creating accessibility barriers for visually impaired users.

Q: How do you make an element exactly half the width of the screen?

A: width: 50vw; (50 Viewport Width).

Summary

Choosing the right CSS measurement unit determines whether your website is rigid and broken, or fluid and accessible. Modern CSS architecture relies heavily on relative units like rem and % to build responsive layouts that respect user accessibility settings, while reserving absolute px for minor decorative borders.

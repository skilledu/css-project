User Interface

The user interface property allows you to change any element into one of several standard user interface elements. Some of the common properties which are used in CSS3 User interface are:

Value Description
appearance Used to allow the user to make elements as user interface elements
box-sizing Allows to users to fix elements on area in clear way
icon Used to provide the icon on area
resize Used to resize elements which are on area
outline-offset Used to draw the behind the outline
nav-down Used to move down when you have pressed on down arrow button in keypad
nav-left Used to move left when you have pressed on left arrow button in keypad
nav-right Used to move right when you have pressed on right arrow button in keypad
nav-up Used to move up when you have pressed on up arrow button in keypad

Example of resize property

The resize property has three common values as shown below:

Value Description
horizontal Allows the user to resize the element horizontally.
vertical Allows the user to resize the element vertically.
both Allows the user to resize the element both horizontally and vertically.
HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         div {
            border: 2px solid;
            padding: 20px;
            width: 300px;
            resize: both;
            overflow: auto;
         }
      </style>
   </head>
   <body>
      <div>Hello World</div>
   </body>
</html>

CSS3 Outline offset

Outline means drawing a line around the element on the outside of the border.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         div {
            margin: 20px;
            padding: 10px;
            width: 300px;
            height: 100px;
            border: 5px solid pink;
            outline: 5px solid green;
            outline-offset: 15px;
         }
      </style>
   </head>
   <body>
      <div>Hello World</div>
   </body>
</html>

Practical Examples

The single most important CSS UI reset used on every modern website to ensure padding doesn't blow out element widths, plus a user-friendly textarea constraint:

CSS
<style>
/* The universal border-box reset */
*, *::before, *::after {
   box-sizing: border-box;
}

textarea {
   /* Prevents users from breaking the layout by dragging horizontally */
   resize: vertical;

   /* Custom focus ring that sits slightly away from the element */
   outline: 2px solid #3b82f6;
   outline-offset: 4px;
}
</style>

<textarea rows="4" cols="50">Try dragging the corner horizontally. You can't!</textarea>

Common Mistakes

  • Leaving box-sizing as content-box − By default, adding 20px of padding to a 100px wide box makes the box 140px wide. This destroys grid layouts. border-box forces padding to shrink inward, keeping the box exactly 100px wide.
  • Leaving textareas freely resizable − If you don't restrict resize on a <textarea>, users can drag the bottom-right corner horizontally and completely break your page layout.
  • Removing the outline without replacement − As mentioned in pseudo-classes, writing outline: none; on focusable UI elements destroys keyboard accessibility.

Best Practices

  • Always apply box-sizing: border-box universally − This should literally be the first rule in every stylesheet you ever write. It makes CSS math logical and intuitive.
  • Use outline instead of border for focus states − Outlines do not take up physical space, meaning they won't cause your layout to jump or shift when they appear on focus. Borders will.
  • Maintain visible focus states − When customizing the outline of interactive elements, ensure the focus state remains highly visible for keyboard users.

Interview Questions

Q: What is the exact difference between box-sizing: content-box and border-box?

A: In content-box (the default), adding padding or borders increases the total size of the element beyond its defined width/height. In border-box, the defined width/height is strictly maintained, and any padding or borders are subtracted from the internal space.

Q: Why is outline generally preferred over border for indicating focus?

A: outline is drawn outside the element's bounds and does not affect the layout or trigger reflows. Adding a border dynamically on focus adds physical pixels, causing the UI to jump.

Q: How do you prevent a user from resizing a textarea entirely?

A: resize: none;.

Summary

CSS User Interface properties refine how users physically interact with your layout. Declaring box-sizing: border-box is mandatory for sane layout math, while carefully controlling resize and styling accessible outline properties ensures your forms are robust and professional.

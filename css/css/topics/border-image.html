Topic 25

Border Image

CSS Border Image property is used to add an image border to some elements. You don't need to use any HTML code to call the border image. A sample syntax of a border image is as follows −

HTML/CSS 
#borderimg {
   border: 10px solid transparent;
   padding: 15px;
}

The most commonly used values are shown below −

Value Description
border-image-source Used to set the image path
border-image-slice Used to slice the border image
border-image-width Used to set the border image width
border-image-repeat Used to set the border image as rounded, repeated and stretched

Example

Following is the example which demonstrates to set image as a border for elements

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         #borderimg1 {
            border: 10px solid transparent;
            padding: 15px;
            border-image-source: url(assets/images/demo-border.svg);
            border-image-repeat: round;
            border-image-slice: 30;
            border-image-width: 10px;
         }
         #borderimg2 {
            border: 10px solid transparent;
            padding: 15px;
            border-image-source: url(assets/images/demo-border.svg);
            border-image-repeat: round;
            border-image-slice: 30;
            border-image-width: 20px;
         }
         #borderimg3 {
            border: 10px solid transparent;
            padding: 15px;
            border-image-source: url(assets/images/demo-border.svg);
            border-image-repeat: round;
            border-image-slice: 30;
            border-image-width: 30px;
         }
      </style>
   </head>
   <body>
      <p id="borderimg1">This is an image border example.</p>
<p id="borderimg2">This is an image border example.</p>
<p id="borderimg3">This is an image border example.</p>
   </body>
</html>

Practical Examples

Creating an intricate, resizable vintage picture frame around a photo using a single 9-slice image:

CSS
<style>
.vintage-frame {
   /* 1. Provide a physical width for the image to exist inside */
   border: 20px solid transparent;

   /* 2. Set the source image */
   border-image-source: url("assets/images/demo-border.svg");

   /* 3. Slice the corners at 30px (unitless) and stretch the edges */
   border-image-slice: 30;
   border-image-repeat: stretch;
}
</style>

<div class="vintage-frame" style="width:200px; padding:20px; text-align:center; margin:20px;">I have a vintage border!</div>

Common Mistakes

  • Forgetting to define a standard border-width − A border-image paints itself INSIDE the element's border area. If you don't define border: 10px solid transparent;, there is no physical space for the image to render, and nothing will appear.
  • Adding units (px) to the slice property − Writing border-image-slice: 30px; is a syntax error. The slice property expects a unitless number (representing pixels for raster images) or a percentage.
  • Not providing a solid fallback − If the image URL 404s, your element will have a transparent border. Always provide a fallback like border: 10px solid black;.

Best Practices

  • Use SVGs for border images − Since border images are stretched and tiled, using vector SVG files ensures the borders look perfectly crisp on high-DPI (Retina) displays.
  • Understand 9-Slice Scaling − border-image-slice cuts the image into 9 zones (4 corners, 4 edges, 1 center). The corners remain fixed, while the edges stretch or repeat. Visualizing this grid is key to mastering the property.

Interview Questions

Q: Does border-image-slice require a unit like px?

A: No, it requires a unitless integer (which implies pixels for raster images) or a percentage.

Q: What does the fill keyword do when added to border-image-slice?

A: By default, the center slice (the 9th zone) of the border image is discarded. Adding the fill keyword forces the center slice to act as the background image of the element.

Q: What happens to a border-image if no border-width is defined on the element?

A: It will not be visible, because the physical border area width is 0.

Summary

The border-image property brings complex, decorative borders to the web without needing massive, unscalable background images. By understanding how the 9-slice grid works and remembering to provide a physical border-width for it to paint on, you can create highly detailed, responsive UI frames.

Topic 11

CSS Display

The display property is the most important CSS property for controlling layout. Every HTML element has a default display value depending on what type of element it is.

Display Values

ValueDescription
blockTakes up the full width available and starts on a new line (e.g. <div>, <h1>).
inlineTakes up only as much width as necessary and does not start on a new line (e.g. <span>, <a>).
inline-blockLike inline elements, they do not start on a new line, but you CAN set width and height values on them.
noneRemoves the element completely from the document. It will not take up any space.

Note: Modern layouts typically use flex or grid, which are incredibly powerful and have their own dedicated chapters later in this tutorial!

Example

CSS
.box-block {
   display: block;
}

.box-inline {
   display: inline;
}

.box-hidden {
   display: none;
}

Comparison Table

DisplayStarts on new line?Respects width/height?Margin/Padding behavior
blockYesYesTop/Bottom and Left/Right margins both work.
inlineNoNoTop/Bottom margins/padding do not push other elements away.
inline-blockNoYesFully respects margin and padding on all sides.

Practical Examples

Converting a standard unordered list into a horizontal navigation bar using inline-block:

CSS
<style>
.nav-list {
   list-style: none;
   padding: 0;
}

.nav-item {
   /* Elements sit side-by-side but respect padding and margins */
   display: inline-block;
   margin-right: 20px;
}

.nav-link {
   display: block;
   padding: 10px 15px;
   background-color: #eee;
}
</style>

<ul class="nav-list">
  <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
  <li class="nav-item"><a class="nav-link" href="#">About</a></li>
</ul>

Common Mistakes

  • Setting width/height on inline elements − Beginners often try to set a height on a <span> or <a> tag. Inline elements completely ignore width, height, and top/bottom margins. You must change them to inline-block or block first.
  • Confusing display: none with visibility: hidden − display: none completely removes the element from the document flow (as if it doesn't exist). visibility: hidden makes it invisible, but it still takes up empty physical space in the layout.
  • Forgetting the whitespace gap − inline-block elements will have a small ~4px gap between them if there is a line break in the HTML source code, which can unexpectedly break pixel-perfect grid layouts.

Best Practices

  • Use display: block to increase click targets − Always change <a> tags inside menus from inline to block so the entire padded area becomes clickable, not just the text itself.
  • Limit inline-block for complex layouts − While great for simple button rows, if you are building complex multi-column layouts, use Flexbox or Grid instead of fighting with inline-block whitespace gaps.

Interview Questions

Q: What is the difference between block and inline-block?

A: A block element forces a line break before and after it, taking up the full width available. An inline-block element sits side-by-side with other inline elements, but unlike a pure inline element, it allows you to set width, height, and vertical margins.

Q: Why can't I set a top margin on an inline element?

A: Because inline elements are designed to flow with text. They only affect horizontal spacing (left/right margin and padding), ignoring vertical spacing to prevent disrupting the line-height of the paragraph.

Q: What is the difference between display: none and visibility: hidden?

A: display: none removes the element entirely from the flow. visibility: hidden leaves the element in the flow, occupying space, but makes it completely transparent.

Summary

The display property is the most fundamental concept in CSS layout. Knowing exactly how block, inline, and inline-block elements behave by default—and knowing when to override them—is the first step to mastering web structure before moving on to advanced systems like Flexbox.

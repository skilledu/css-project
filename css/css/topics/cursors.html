Topic 44

Cursors

The cursor property of CSS allows you to specify the type of cursor that should be displayed to the user. One good usage of this property is in using images for submit buttons on forms. By default, when a cursor hovers over a link, the cursor changes from a pointer to a hand. However, it does not change form for a submit button on a form. Therefore, whenever someone hovers over an image that is a submit button, it provides a visual clue that the image is clickable. The following table shows the possible values for the cursor property:

Value Description
autoShape of the cursor depends on the context area it is over.
crosshairA crosshair or plus sign
defaultAn arrow
pointerA pointing hand
moveThe 'I' bar (Move indicator)
e-resizeEdge of a box is to be moved right (east)
ne-resizeEdge of a box is to be moved up and right (north/east)
nw-resizeEdge of a box is to be moved up and left (north/west)
n-resizeEdge of a box is to be moved up (north)
se-resizeEdge of a box is to be moved down and right (south/east)
sw-resizeEdge of a box is to be moved down and left (south/west)
s-resizeEdge of a box is to be moved down (south)
w-resizeEdge of a box is to be moved left (west)
textThe I bar
waitAn hour glass
helpA question mark or balloon, ideal for use over help buttons
<url>The source of a cursor image file

NOTE: You should try to use only these values to add helpful information for users, and in places they would expect to see that cursor. For example, using the crosshair when someone hovers over a link can confuse visitors.

Example

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <p>Move the mouse over the words to see the cursor change:</p>
      <div style="cursor:auto">Auto</div>
      <div style="cursor:crosshair">Crosshair</div>
      <div style="cursor:default">Default</div>
      <div style="cursor:pointer">Pointer</div>
      <div style="cursor:move">Move</div>
      <div style="cursor:e-resize">e-resize</div>
      <div style="cursor:ne-resize">ne-resize</div>
      <div style="cursor:nw-resize">nw-resize</div>
      <div style="cursor:n-resize">n-resize</div>
      <div style="cursor:se-resize">se-resize</div>
      <div style="cursor:sw-resize">sw-resize</div>
      <div style="cursor:s-resize">s-resize</div>
      <div style="cursor:w-resize">w-resize</div>
      <div style="cursor:text">text</div>
      <div style="cursor:wait">wait</div>

</html>

Practical Examples

Applying specific cursors to UI elements to give users clear feedback about what can be clicked and what is disabled:

HTML/CSS
<style>
/* A custom div acting as a button needs the pointer cursor */
.custom-btn {
   cursor: pointer;
   background-color: #3b82f6;
}

/* A disabled submit button */
.submit-btn[disabled] {
   cursor: not-allowed;
   opacity: 0.5;
}

/* A read-only input field */
input[readonly] {
   cursor: default;
   background-color: #f3f4f6;
}
</style>

<div class="custom-btn" style="padding:10px; background:blue; color:white; width:fit-content; margin-bottom:10px;">Clickable Div</div>
<button class="submit-btn" disabled>Disabled Button</button>
<br><br>
<input type="text" value="Read only" readonly>

Common Mistakes

  • Forgetting cursor: pointer on custom interactive elements − If you attach a JavaScript click listener to a <div> or an SVG icon, the browser will not automatically change the cursor. Users won't know it's clickable unless you manually add cursor: pointer.
  • Using pointer on non-clickable elements − Adding a pointer cursor to a decorative image just because it looks nice. This is extremely frustrating for users who will click it expecting something to happen.
  • Assuming <button> tags have a pointer by default − Surprisingly, many browsers (like older Safari versions) use the standard default arrow for buttons. It is a best practice to explicitly declare button { cursor: pointer; } in your CSS reset.

Best Practices

  • Provide feedback for disabled states − Always use cursor: not-allowed combined with a lower opacity when a form button or input is temporarily disabled.
  • Use cursor: text for custom inputs − If you build a complex custom search bar out of divs, ensure it shows the I-beam text cursor so users know they can click to type.
  • Don't rely on cursors alone − Cursor changes are a visual-only cue. They shouldn't be the only indicator of interactivity, as keyboard-only and touchscreen users will not see them before interacting.

Interview Questions

Q: What cursor value indicates to a user that an element is a clickable link?

A: cursor: pointer; (it typically displays as a hand with an extended index finger).

Q: What cursor should be used for a form submit button that is currently disabled due to invalid inputs?

A: cursor: not-allowed;

Q: Can you use a custom image as a cursor?

A: Yes. You can use cursor: url("custom-cursor.png"), auto; (always provide a fallback like auto or pointer in case the image fails to load).

Summary

Cursors are a vital part of web accessibility and user experience. They provide immediate, non-verbal feedback to the user about how they can interact with the interface. Ensuring your clickable elements have pointers and your disabled elements show restrictions builds trust and intuition into your design.

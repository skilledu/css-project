Colors — Basics

CSS uses color values to specify colors for text, backgrounds, borders, and other decorative effects. You can specify colors in several formats: Hex codes, RGB values, and keyword names.

Code Example

CSS 
/* Hex color */
h1 { color: #FF0000; }       /* Red */

/* RGB color */
p  { color: rgb(0, 128, 0); } /* Green */

/* Keyword color */
body { background-color: navy; }

/* Hex shorthand */
a  { color: #0F0; }           /* Same as #00FF00 */

Practical Examples

A standard button component utilizing HEX colors for the background, border, and text to ensure exact color matching:

CSS
<style>
.btn-primary {
   /* Named colors are rarely used in production */
   background-color: #3b82f6;
   color: #ffffff;
   border: 1px solid #2563eb;
}

.btn-primary:hover {
   background-color: #1d4ed8;
}
</style>

<button class="btn-primary">Primary Action</button>

Common Mistakes

  • Forgetting the hash (#) in HEX colors − Writing color: 333333; instead of color: #333333;. The browser will ignore the invalid value entirely.
  • Using unreadable color names − Relying on named colors like color: goldenrod; which provides very little control over exact branding shades and often fails contrast tests.
  • Low Contrast Ratios − Using light gray text on a white background (e.g., color: #cccccc on #ffffff). This makes the text unreadable and fails accessibility guidelines.

Best Practices

  • Stick to HEX or RGB in Production − They provide millions of exact shades, allowing you to match brand guidelines perfectly.
  • Use 3-Digit HEX Shorthand − You can abbreviate HEX codes if the pairs match. #ff0000 can be written as #f00 to save space.
  • Check Contrast for Accessibility − Color contrast between text and background matters greatly for readability, especially for low-vision users. A common guideline is to check contrast ratios via a contrast checker tool to ensure a minimum of 4.5:1, rather than relying purely on visual judgment.

Interview Questions

Q: How many characters does a valid HEX color code contain?

A: Either 3 (shorthand, like #fff), 6 (standard, like #ffffff), or 8 (if including an alpha transparency channel at the end).

Q: What does the RGB format stand for?

A: Red, Green, Blue. It defines colors by specifying the intensity of those three light colors on a scale from 0 to 255.

Q: How do you represent pure black in both HEX and RGB?

A: HEX: #000000. RGB: rgb(0, 0, 0).

Q: Why are CSS named colors rarely used in professional web design?

A: There are only 140 named colors, which is far too limiting for exact brand color matching, and their names can be ambiguous across different screen calibrations.

Summary

Colors breathe life into your web layout. While CSS offers simple named colors for quick prototyping, mastering 6-digit HEX codes and RGB values gives you access to the entire visual spectrum. Always prioritize high contrast between your text and backgrounds to ensure your site is readable for everyone.

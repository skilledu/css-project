Topic 22

Background

This chapter teaches you how to set backgrounds of various HTML elements. You can set the following background properties of an element −

PropertyDescription
background-coloris used to set the background color of an element.
background-imageis used to set the background image of an element.
background-repeatis used to control the repetition of an image in the background.
background-positionis used to control the position of an image in the background.
background-attachmentis used to control the scrolling of an image in the background.
backgroundis used as a shorthand to specify a number of other background properties.

Repeat the Background Image

The following example demonstrates how to repeat the background image if an image is small.

You can use the no-repeat value for the background-repeat property if you don't want to repeat an image; in this case the image will display only once. By default, the background-repeat property will have the repeat value.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         body {
            background-image: url('assets/images/demo-pattern.png');
            background-size: 100px;
            background-repeat: repeat;
            min-height: 100vh;
         }
      </style>
   </head>
   <body>
      <p>Image repeats in both directions (default)</p>
   </body>
</html>

Shorthand Property

You can use the background property to set all the background properties at once. For example −

HTML/CSS
<p style="background:url(assets/images/demo-pattern.png);
            background-size: 100px repeat fixed;">
This paragraph has fixed repeated background image.
</p>

Practical Examples

A common "Hero Section" pattern utilizing the background shorthand property to display a large, centered, non-repeating cover image:

CSS
<style>
/* Shorthand: color image repeat attachment position */
.hero-section {
   /* Note: The fallback color #333 loads if the image fails */
   background: #333 url("assets/images/demo-photo.jpg") no-repeat center center;

   /* Force the image to cover the entire container */
   background-size: cover;
   height: 400px;
}
</style>

<div class="hero-section">
  <h2>Hero Title</h2>
</div>

Common Mistakes

  • Forgetting a fallback color − If you apply a background image behind white text, but the image fails to load (or loads slowly), the white text will become invisible against the default white page. Always provide a fallback background-color.
  • Using massive, unoptimized images − Loading a 5MB image for a background causes massive performance delays. Always compress background images before deploying.
  • Not preventing repeat − By default, background images tile (repeat) endlessly. Forgetting background-repeat: no-repeat; often results in ugly tiled layouts on large screens.

Best Practices

  • Use background-size: cover for full-width sections − This ensures your image scales beautifully to fill the container without distorting its aspect ratio.
  • Add Overlays for Text Legibility − If you put text over a busy background image, use a semi-transparent dark overlay (e.g., using a linear-gradient) to ensure the text remains readable.
  • Master the Shorthand − Use the background shorthand to declare the color, image, repeat, and position in a single line to keep your CSS clean.
  • Optimize background images − Large unoptimized background images can severely slow down page load times. Always compress background images before uploading them.

Interview Questions

Q: What is the difference between background-size: cover and contain?

A: cover scales the image to completely fill the container (cropping the edges if necessary). contain scales the image so the entire image is visible (leaving empty letterbox space if the aspect ratios don't match).

Q: How do you create a "parallax" scrolling effect with a background image?

A: By using background-attachment: fixed;, which locks the background image to the viewport while the rest of the page scrolls over it.

Q: What is the default behavior of a background image if it is smaller than its container?

A: It will repeat (tile) horizontally and vertically until it fills the entire container.

Q: Can an element have multiple background images?

A: Yes! You can separate multiple images with commas in the background-image property. The first image listed will appear on top.

Summary

The background properties allow you to style the layer underneath your content. Whether you are using solid colors or complex images, mastering properties like background-size and background-repeat ensures your visual design scales perfectly across all device sizes. Always remember your fallback color!

CSS Variables (Custom Properties)

Introduction to CSS Variables

CSS variables (officially known as custom properties) are entities defined by CSS authors that contain specific values to be reused throughout a document. They make it easy to maintain themes, colors, and sizing across a large project.

Declaring and Using Variables

Variables are declared using double hyphens (--) and accessed using the var() function.

CSS
/* Declaring globally */
:root {
   --primary-color: #3b82f6;
   --spacing-md: 16px;
}

/* Using variables */
.btn {
   background-color: var(--primary-color);
   padding: var(--spacing-md);
}

Fallback Values

You can provide a fallback value in the var() function in case the variable is not defined.

CSS
.text {
   /* Will use #333 if --text-color is missing */
   color: var(--text-color, #333);
}

Scoping (Global vs Local)

Variables follow CSS cascading rules. Variables declared in the :root pseudo-class are global. Variables declared inside a specific selector are local to that element and its children.

CSS
.card {
   --card-bg: #fff; /* Local variable */
   background-color: var(--card-bg);
}

.card-dark {
   --card-bg: #222; /* Overriding local variable */
}

Theming

Variables make dark mode toggling extremely easy. You just swap the variable values!

CSS
:root {
   --bg-color: #ffffff;
   --text-color: #000000;
}

body.dark-theme {
   --bg-color: #1a1a1a;
   --text-color: #ffffff;
}

body {
   background-color: var(--bg-color);
   color: var(--text-color);
}

Practical Examples

Here is a complete, working example using CSS variables for theming.

HTML/CSS
<!DOCTYPE html>
<html>
   <head>
      <style>
         :root {
            --primary-color: #4CAF50;
            --text-color: white;
         }
         .btn {
            background-color: var(--primary-color);
            color: var(--text-color);
            padding: 15px 32px;
            text-align: center;
            font-size: 16px;
            border: none;
            cursor: pointer;
         }
      </style>
   </head>
   <body>
      <h1>CSS Variables Example</h1>
      <button class="btn">Themed Button</button>
   </body>
</html>

Common Mistakes

  • Case Sensitivity: CSS variables are case-sensitive. --primaryColor is not the same as --primarycolor.
  • Forgetting the var() function: You cannot write color: --primary-color;. It must be color: var(--primary-color);.

Best Practices

  • Use :root for Globals: Always define your global design tokens (colors, typography, spacing) in the :root selector.
  • Semantic Naming: Name variables based on their intent (--color-danger) rather than their value (--color-red).

Interview Questions

  • What is the difference between CSS Variables and SASS Variables?
    CSS variables exist in the DOM, meaning they can be changed dynamically with JavaScript and respect the cascade. SASS variables are compiled away into hardcoded values.
  • Can CSS variables be updated with JavaScript?
    Yes! You can use element.style.setProperty('--var-name', 'value').

Summary

CSS Custom Properties (Variables) bring programmatic power to raw CSS. They reduce repetition, enable dynamic theming (like light/dark mode) natively, and can be manipulated via JavaScript, making them an indispensable part of modern CSS architecture.

Topic 39

Animation

Animation is process of making shape changes and creating motions with elements.

HTML/CSS
<!DOCTYPE html>
<html>
   <head>
      <style>
         h1 {
            animation: slidein 4s infinite alternate;
         }
         @keyframes slidein {
            from {
               margin-left: 100%;
               width: 300%;
            }
            75% {
               font-size: 300%;
               margin-left: 25%;
               width: 150%;
               color: red;
            }
            to {
               margin-left: 0%;
               width: 100%;
               color: blue;
            }
         }
      </style>
   </head>
   <body>
      <h1>Hello World</h1>
   </body>
</html>

Practical Examples

A smooth, infinitely pulsing "Live" indicator dot using the @keyframes rule:

HTML/CSS
<style>
@keyframes pulse {
   0% {
      transform: scale(0.95);
      box-shadow: 0 0 0 0 rgba(220, 38, 38, 0.7);
   }
   70% {
      transform: scale(1);
      box-shadow: 0 0 0 10px rgba(220, 38, 38, 0);
   }
   100% {
      transform: scale(0.95);
      box-shadow: 0 0 0 0 rgba(220, 38, 38, 0);
   }
}

.live-indicator {
   width: 12px;
   height: 12px;
   background-color: #dc2626;
   border-radius: 50%;
   /* name | duration | timing-function | delay | iteration-count | direction */
   animation: pulse 2s infinite;
}
</style>

<div style="display:flex; align-items:center; gap:10px; padding:20px;">
  <div class="live-indicator"></div>
  <span>Live Now</span>
</div>

Common Mistakes

  • Animations snapping back to start − By default, an element immediately snaps back to its 0% state when an animation finishes. If you want the element to stay in its 100% state permanently, you must add animation-fill-mode: forwards;.
  • Animating layout properties − Using @keyframes to animate margin, top/left, or width. This forces layout recalculations and destroys framerates. Always animate transform and opacity.
  • Forgetting prefers-reduced-motion − Some users suffer from motion sickness. Failing to wrap infinite or aggressive animations in a @media (prefers-reduced-motion: reduce) query fails accessibility standards.

Best Practices

  • Use CSS Variables in Keyframes − If you want multiple elements to pulse to different sizes, use transform: scale(var(--pulse-size, 1.2)) inside your keyframes. This allows you to reuse one animation rule across dozens of elements.
  • Use alternate for smooth looping − If you want an animation to bounce back and forth smoothly (like a floating ghost), use animation-direction: alternate; so it plays 0% to 100%, then 100% back to 0%.
  • Respect user preferences − Use the prefers-reduced-motion media query to disable or reduce animations for users who get motion sickness from excessive movement on screen.

Interview Questions

Q: What is the primary difference between a CSS transition and a CSS animation?

A: A transition strictly requires a trigger (like a hover state or JS class change) to move from an initial state to a final state. An animation (using @keyframes) can run automatically on page load, loop infinitely, and pass through multiple complex intermediate steps (e.g., 25%, 50%, 75%).

Q: What does animation-fill-mode: forwards do?

A: It instructs the element to retain the styling values defined in the final keyframe (100%) after the animation finishes playing, preventing it from snapping back to its original state.

Q: How do you pause a CSS animation?

A: By setting animation-play-state: paused;.

Summary

CSS Animations via the @keyframes rule offer incredibly powerful, multi-step sequence controls. They completely replace the need for heavy JavaScript animation libraries for most UI interactions. By mastering keyframe percentages and the animation shorthand properties, you can bring complex, performant motion to your web apps.

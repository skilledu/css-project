CSS Transitions

CSS transitions allow you to change property values smoothly, over a given duration, rather than having them snap instantly. (e.g. from state A to state B).

Note: Transitions are distinct from Animations. Transitions require a trigger (like :hover) and go from state A to B. Animations (using @keyframes) can run automatically, loop, and have multiple complex steps. We cover Animations in a separate chapter!

Transition Properties

Property Description
transition-property The specific CSS property you want to transition (e.g., background-color).
transition-duration How long the transition takes (e.g., 0.3s).
transition-timing-function The speed curve of the transition.
transition-delay A delay before the transition starts.
transition The shorthand property for the 4 properties above.

Common Timing Functions

Value Description
ease Slow start, then fast, then end slowly (default).
linear Same speed from start to end.
ease-in Slow start.
ease-out Slow end.
ease-in-out Slow start and end.
cubic-bezier(n,n,n,n) Lets you define your own custom speed curve.

Examples

Example 1: Button Hover Color Change

CSS
.btn {
   background-color: blue;
   transition: background-color 0.3s ease-in-out;
}

.btn:hover {
   background-color: red;
}

Example 2: Scale Transformation

CSS
.card {
   transform: scale(1);
   transition: transform 0.2s linear;
}

.card:hover {
   transform: scale(1.1);
}

Practical Examples

A modern, interactive button that smoothly changes color and scales up slightly when hovered:

CSS
<style>
.btn-interactive {
   background-color: #3b82f6;
   color: white;
   padding: 10px 20px;
   transform: scale(1);

   /* Apply the transition to the DEFAULT state, not the hover state */
   transition: background-color 0.3s ease, transform 0.2s ease-in-out;
}

.btn-interactive:hover {
   background-color: #1d4ed8;
   transform: scale(1.05);
}
</style>

<div style="padding:20px; text-align:center;">
  <button class="btn-interactive">Hover Me!</button>
</div>

Common Mistakes

  • Putting the transition on the :hover state − If you put the transition property inside .btn:hover, the animation will play smoothly when the mouse enters, but will instantly snap back abruptly when the mouse leaves. Always put it on the default state!
  • Transitioning display − You cannot transition an element from display: none to display: block. It will snap instantly. You must transition opacity or visibility instead.
  • Transitioning width or height − Animating layout properties (like width, height, margin) forces the browser to recalculate the layout on every single frame, causing horrible lag. Transition transform instead.
  • Making transitions too slow − A 1-second hover transition feels incredibly sluggish to users. Hover effects should feel snappy.

Best Practices

  • Keep it snappy (0.2s - 0.3s) − The sweet spot for UI interactions (like hovers and clicks) is between 200ms and 300ms.
  • Animate Hardware-Accelerated Properties − Whenever possible, only transition transform (scale, translate) and opacity. The browser hands these off to the GPU, guaranteeing a buttery-smooth 60fps. Transitioning these performs vastly better than transitioning width, height, top, or left, because the former do not trigger layout recalculation.
  • Specify the property − Avoid using transition: all. It forces the browser to monitor everything, which can cause performance drops. Explicitly state the properties you want to animate.

Interview Questions

Q: What is the default timing-function of a transition?

A: ease, which starts slow, goes fast in the middle, and ends slowly.

Q: Why should you transition transform: scale() instead of width?

A: Transitioning width triggers layout recalculations and repaints on every frame, causing performance lag. transform is handled by the GPU and does not affect surrounding elements, resulting in a smooth animation.

Q: How do you transition multiple properties at different speeds?

A: By separating them with commas: transition: opacity 0.2s, transform 0.5s;.

Summary

Transitions are the easiest way to make a website feel premium and interactive. By applying transitions to the default state (not the hover state) and keeping durations short and snappy, you can dramatically improve the user experience. Always prioritize animating opacity and transform for optimal performance.

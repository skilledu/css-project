CSS Float

The float property is used for positioning and formatting content e.g. let an image float left to the text in a container.

Important Note: While floats were historically used for entire website layouts, Flexbox and Grid are the modern, preferred approaches. Today, float should mainly be used for its original purpose: wrapping text around images.

Float Values

ValueDescription
leftThe element floats to the left of its container.
rightThe element floats to the right of its container.
noneThe element does not float (default).
CSS
img {
   float: right;
   margin: 0 0 10px 10px;
}

The Clearfix Problem

If a floating element is taller than the containing element, it will "overflow" outside of its container. We can fix this using a "clearfix".

Legacy method: Add an empty element after the float and apply clear: both;.

Modern Hack (::after): The modern way to fix this is to use the ::after pseudo-element on the container:

CSS
.clearfix::after {
   content: "";
   clear: both;
   display: table;
}

Practical Examples

The classic, appropriate use case for a float: wrapping text around an article image, utilizing the modern clearfix hack on the parent container:

CSS
<style>
.article-img {
   float: left;
   margin-right: 20px;
   margin-bottom: 10px;
   width: 300px;
}

/* The modern Clearfix hack applied to the parent container */
.clearfix::after {
   content: "";
   display: table;
   clear: both;
}
</style>

<div class="clearfix" style="border:1px solid #ccc; padding:10px;">
  <img class="article-img" src="../assets/images/demo-photo.jpg" alt="Placeholder" style="width:100px;">
  <p>This text flows around the floated image. The clearfix ensures the parent container expands to fit the image height!</p>
</div>

Common Mistakes

  • Using floats for page layout − Building 3-column layouts using float: left (the 2010 way). This requires complex math, clearing hacks, and breaks easily. Always use Flexbox or Grid for structural layouts today.
  • Forgetting to clear floats (Container Collapse) − If a parent container only contains floated children, the parent's height will collapse to 0 pixels, causing the background to disappear and subsequent elements to overlap.
  • Using the wrong clear value − Using clear: left when you actually have elements floated to the right. clear: both is almost always the safest and most reliable choice.

Best Practices

  • Restrict float to typography − Only use floats for their original intended purpose: allowing text to naturally wrap around an image or a pull-quote.
  • Use a utility class for clearing − Keep a standard .clearfix utility class in your global stylesheet so you can easily apply it to any parent container that holds floated elements.

Interview Questions

Q: What does the float property actually do?

A: It removes an element from the normal document flow and pushes it to the left or right of its container, allowing text and inline elements to wrap around it.

Q: What is the "clearfix" hack?

A: It is a CSS technique using the ::after pseudo-element to force a parent container to expand and contain its floated children, preventing it from collapsing to zero height.

Q: Why don't we use floats for grid layouts anymore?

A: Because floats were designed for text wrapping, not layout structure. They require complex math, manual clearing, and lack the alignment and distribution capabilities built natively into modern tools like Flexbox and CSS Grid.

Summary

While float has been retired as a primary layout tool in favor of Flexbox and Grid, it remains an essential tool for editorial design (wrapping text around images). Understanding how floats affect the document flow and how to "clear" them is still a required skill for any CSS developer.

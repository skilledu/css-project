CSS Grid

Introduction to CSS Grid

CSS Grid Layout is the most powerful layout system available in CSS. It is a 2-dimensional system, meaning it can handle both columns and rows, unlike Flexbox which is largely a 1-dimensional system.

Flexbox vs Grid: Use Flexbox for alignment in one direction (a row of buttons). Use Grid for overall page layout or complex layouts requiring strict control over both rows and columns.

Set an element to grid using display: grid (block-level) or display: inline-grid (inline-level).

CSS
.grid-container {
   display: grid;
}

Grid Container Properties

The following properties apply to the grid container (the parent element).

grid-template-columns

Defines the number of columns and their widths. You can use the fr (fractional) unit to distribute remaining space.

CSS
.grid-container {
   /* 3 columns: 200px, 1 fraction, 2 fractions */
   grid-template-columns: 200px 1fr 2fr;
}

Use repeat() and minmax() for responsive grids without media queries:

CSS
.grid-container {
   grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

grid-template-rows

Defines the heights of the rows in the grid.

CSS
.grid-container {
   grid-template-rows: 100px auto 100px;
}

grid-template-areas

Allows you to name sections of the grid and place items intuitively.

CSS
.grid-container {
   grid-template-areas:
      "header header header"
      "sidebar content content"
      "footer footer footer";
}

gap / row-gap / column-gap

Defines the space between the rows and columns.

CSS
.grid-container {
   gap: 20px;
}

justify-items & align-items

justify-items aligns items horizontally inside their grid cells. align-items aligns them vertically.

CSS
.grid-container {
   justify-items: center;
   align-items: center;
}

justify-content & align-content

Used to align the entire grid inside the container, if the grid is smaller than the container itself.

CSS
.grid-container {
   justify-content: center;
}

Grid Item Properties

The following properties apply to the individual grid items (the child elements).

grid-column & grid-row

Shorthands for specifying where an item starts and ends. You can use span to stretch across tracks.

CSS
.item1 {
   grid-column: 1 / 3; /* Start at column line 1, end at 3 */
   grid-row: span 2;  /* Stretch across 2 rows */
}

grid-area

Used to place an item into a named area created by grid-template-areas.

CSS
.item-header {
   grid-area: header;
}

justify-self & align-self

Overrides the container's alignment for a single specific item inside its cell.

CSS
.item1 {
   justify-self: end;
   align-self: end;
}

Responsive 12-Column Example

Building a classic 12-column grid layout is incredibly simple with CSS Grid:

CSS
.grid-12 {
   display: grid;
   grid-template-columns: repeat(12, 1fr);
   gap: 16px;
}

.span-4 {
   grid-column: span 4;
}

.span-8 {
   grid-column: span 8;
}

Practical Examples

Here is a complete, working example of a Grid layout.

HTML/CSS
<!DOCTYPE html>
<html>
   <head>
      <style>
         .grid-container {
            display: grid;
            grid-template-columns: auto auto auto;
            background-color: #2196F3;
            padding: 10px;
            gap: 10px;
         }
         .grid-item {
            background-color: rgba(255, 255, 255, 0.8);
            border: 1px solid rgba(0, 0, 0, 0.8);
            padding: 20px;
            font-size: 30px;
            text-align: center;
         }
      </style>
   </head>
   <body>
      <h1>Grid Layout Example</h1>
      <div class="grid-container">
         <div class="grid-item">1</div>
         <div class="grid-item">2</div>
         <div class="grid-item">3</div>
         <div class="grid-item">4</div>
         <div class="grid-item">5</div>
         <div class="grid-item">6</div>
      </div>
   </body>
</html>

Common Mistakes

  • Overusing Grid: Using Grid for everything. If you just need to align an icon and text, Flexbox is much simpler!
  • Confusing lines vs tracks: grid-column: 1 / 3 means it spans from line 1 to line 3 (which covers 2 columns, not 3).

Best Practices

  • auto-fit and minmax(): Use these functions to create highly responsive grids that wrap automatically without needing complex media queries.
  • Named Areas: For page layouts, grid-template-areas makes your CSS incredibly readable and easy to maintain.

Interview Questions

  • What is the difference between auto-fill and auto-fit in Grid?
    auto-fill fills the row with as many columns as it can, even if they are empty. auto-fit collapses empty columns and stretches the filled ones to fit the space.
  • What is the fr unit?
    It stands for fractional unit. It represents a fraction of the available free space in the grid container.

Summary

CSS Grid is a robust 2D layout tool. While it has a steeper learning curve than Flexbox, its ability to control both rows and columns simultaneously, and create complex responsive designs with minimal code (via named areas and the fr unit), makes it an essential tool for modern web development.

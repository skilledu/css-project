3D Transforms

CSS 3D transforms allow you to format elements using 3D transformations. You can move, rotate, scale, and skew elements in three-dimensional space.

3D Transform Methods

Function Description
matrix3d(n,n,n,n,n,n,n,n,n,n,n,n,n,n,n,n)Defines a 3D transformation, using a 4x4 matrix of 16 values
translate3d(x,y,z)Defines a 3D translation
translateX(x)Defines a 3D translation, using only the value for the X-axis
translateY(y)Defines a 3D translation, using only the value for the Y-axis
translateZ(z)Defines a 3D translation, using only the value for the Z-axis
scale3d(x,y,z)Defines a 3D scale transformation
scaleX(x)Defines a 3D scale transformation by giving a value for the X-axis
scaleY(y)Defines a 3D scale transformation by giving a value for the Y-axis
scaleZ(z)Defines a 3D scale transformation by giving a value for the Z-axis
rotate3d(x,y,z,angle)Defines a 3D rotation
rotateX(angle)Defines a 3D rotation along the X-axis
rotateY(angle)Defines a 3D rotation along the Y-axis
rotateZ(angle)Defines a 3D rotation along the Z-axis
perspective(n)Defines a perspective view for a 3D transformed element

Example

CSS 
div {
   width: 100px;
   height: 100px;
   background: red;
   transform: rotateX(150deg);
}

Practical Examples

A classic flipping card interaction, where hovering over the container rotates the card 180 degrees in 3D space to reveal the back side:

CSS
<style>
/* The parent MUST have perspective to create 3D depth */
.card-container {
   perspective: 1000px;
}

.card-inner {
   transition: transform 0.6s;
   transform-style: preserve-3d; /* Allows children to live in 3D space */
}

.card-container:hover .card-inner {
   transform: rotateY(180deg); /* Flips it horizontally */
}

.card-back {
   /* Hides the back side of the element when it is flipped away from the user */
   backface-visibility: hidden;
   transform: rotateY(180deg);
}
</style>

<div class="card-container" style="width:200px; height:300px;">
  <div class="card-inner" style="position:relative; width:100%; height:100%;">
    <div style="position:absolute; width:100%; height:100%; background:blue; color:white; display:flex; align-items:center; justify-content:center; backface-visibility:hidden;">FRONT (Hover me)</div>
    <div class="card-back" style="position:absolute; width:100%; height:100%; background:red; color:white; display:flex; align-items:center; justify-content:center; top:0; left:0;">BACK</div>
  </div>
</div>

Common Mistakes

  • Forgetting the perspective property − If you apply transform: rotateX(45deg) without setting perspective on the parent, the element will just look like it awkwardly squished vertically in 2D space. Perspective gives the rotation 3D depth.
  • Forgetting backface-visibility: hidden − When building a flipping card, if you don't hide the backface, the user will just see a mirrored, backwards version of the front of the card when it rotates 180 degrees.
  • Applying perspective to the transformed element itself − The perspective property must almost always be applied to the PARENT container holding the elements you want to transform in 3D.

Best Practices

  • Use translate3d for Performance Hacks − Even if you only need a 2D translation, writing transform: translate3d(x, y, 0); forces the browser to hardware-accelerate the element on the GPU, which can resolve flickering or lag on older devices.
  • Keep perspective values between 500px and 1000px − A very low perspective (like 100px) creates a massive, distorted fisheye lens effect. A very high value (like 3000px) flattens the 3D effect completely.
  • Prioritize Performance − 3D transforms are GPU-accelerated, meaning preferring transform over animating top or left will result in much smoother performance.

Interview Questions

Q: What does the perspective property do in CSS?

A: It defines how far away the object is from the user. It gives a 3D-transformed element depth, determining how intense the 3D effect and foreshortening will appear.

Q: What is the purpose of transform-style: preserve-3d?

A: By default, nested elements are flattened into the 2D plane of their parent. preserve-3d allows children to maintain their own independent 3D positioning inside a 3D-transformed parent.

Q: What happens if you don't use backface-visibility: hidden on a 180-degree flipped element?

A: The element remains visible, but it appears completely mirrored (backwards) to the user.

Summary

3D Transforms bring depth and realism to web interfaces. By combining rotateX, rotateY, and translateZ with a strong perspective on the parent container, you can build engaging, hardware-accelerated interactions like flipping cards and 3D carousels with pure CSS.

Multi Columns

CSS3 supported multi columns to arrange the text as news paper structure.

Some of most common used multi columns properties as shown below −

Value Description
column-count Used to count the number of columns that element should be divided
column-fill Used to decide, how to fill the columns
column-gap Used to decide the gap between the columns
column-rule Used to specifies the number of rules
rule-color Used to specifies the column rule color
rule-style Used to specifies the style rule for column
rule-width Used to specifies the width
column-span Used to specifies the span between columns

Example

Below example shows the arrangement of text as new paper structure.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         .multi {
            /* Column count property */
            -webkit-column-count: 4;
            -moz-column-count: 4;
            column-count: 4;
            /* Column gap property */
            -webkit-column-gap: 40px;
            -moz-column-gap: 40px;
            column-gap: 40px;
            /* Column style property */
            -webkit-column-rule-style: solid;
            -moz-column-rule-style: solid;
            column-rule-style: solid;
         }
      </style>
   </head>
   <body>
      <div class="multi">

For suppose, if user wants to make text as new paper without line, we can do this by removing style syntax as shown below

CSS 
.multi {
   /* Column count property */
   -webkit-column-count: 4;
   -moz-column-count: 4;
   column-count: 4;
   /* Column gap property */
   -webkit-column-gap: 40px;
   -moz-column-gap: 40px;
   column-gap: 40px;
}

Practical Examples

A classic, responsive card grid (like Pinterest) built using the CSS Multi-column layout module, ensuring cards aren't sliced in half:

CSS
<style>
.card-masonry {
   column-width: 300px; /* Responsive: browsers calculate how many columns fit */
   column-gap: 20px;
}

.card {
   /* CRITICAL: Prevents the card from being cut in half across two columns */
   break-inside: avoid;
   margin-bottom: 20px;
   background: #fff;
   border-radius: 8px;
}
</style>

<div class="card-masonry">
  <div class="card" style="height:100px; background:#eee; margin-bottom:10px; padding:10px;">Card 1</div>
  <div class="card" style="height:150px; background:#ddd; margin-bottom:10px; padding:10px;">Card 2</div>
  <div class="card" style="height:80px; background:#ccc; margin-bottom:10px; padding:10px;">Card 3</div>
  <div class="card" style="height:120px; background:#bbb; margin-bottom:10px; padding:10px;">Card 4</div>
</div>

Common Mistakes

  • Using CSS Columns for UI grids − CSS Columns read vertically (top-to-bottom, then left-to-right). If you have a list of products (1, 2, 3, 4), they will stack vertically. If you want a traditional horizontal grid (1, 2 across the top row), you MUST use CSS Grid, not CSS Columns.
  • Forgetting break-inside: avoid − If you put cards or paragraphs in a multi-column layout without this property, the browser will literally slice the card in half at the bottom of Column 1 and render the bottom half at the top of Column 2.
  • Using column-count instead of column-width − column-count: 3 forces exactly 3 columns even on a narrow smartphone, crushing the content. column-width is natively responsive.

Best Practices

  • Use for Masonry Image Galleries − CSS Grid struggles with true masonry (Pinterest-style) layouts where items have varying heights. CSS Multi-columns handles varying heights beautifully, making it the best tool for masonry image galleries.
  • Use column-rule for neat dividers − Instead of hacking borders onto child elements, use column-rule: 1px solid #ccc; to automatically draw perfect vertical lines between your columns.

Interview Questions

Q: What CSS property prevents an element from being split across two columns in a multi-column layout?

A: break-inside: avoid;.

Q: How does column-width act responsively without media queries?

A: It acts as a minimum optimal width. The browser will automatically divide the container width by the column-width value to determine how many columns can fit. As the screen shrinks, the number of columns naturally decreases.

Q: How do you make a headline span completely across all columns?

A: Apply column-span: all; to the headline element.

Summary

The CSS Multi-column Layout module mimics classic newspaper typesetting. While it shouldn't be used for main structural UI layouts, it remains the absolute best, most responsive tool for flowing long text natively and building varying-height masonry layouts like Pinterest.

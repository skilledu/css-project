Topic 26

Using Images

Images play an important role in any webpage. Though it is not recommended to include a lot of images, but it is still important to use good images wherever required.

CSS plays a good role to control image display. You can set the following image properties using CSS.

The border property is used to set the width of an image border.

The height property is used to set the height of an image.

The width property is used to set the width of an image.

The -moz-opacity property is used to set the opacity of an image.

The Image Border Property

The border property of an image is used to set the width of an image border. This property can have a value in length or in %.

A width of zero pixels means no border. Here is the example −

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <img style="border:0px;" src="../assets/images/demo-logo.png" width="150" />
      <br />
      <img style="border:3px dashed red;" src="../assets/images/demo-logo.png" width="150" />
   </body>
</html>

The Image Height Property

The height property of an image is used to set the height of an image. This property can have a value in length or in %. While giving value in %, it applies it in respect of the box in which an image is available.

Example

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <img style="border:1px solid red; height:100px;" src="../assets/images/demo-logo.png" width="150" />
      <br />
      <img style="border:1px solid red; height:50%;" src="../assets/images/demo-logo.png" width="150" />
   </body>
</html>

The Image Width Property

The width property of an image is used to set the width of an image. This property can have a value in length or in %. While giving value in %, it applies it in respect of the box in which an image is available.

Example

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <img style="border:1px solid red; width:150px;" src="../assets/images/demo-logo.png" width="150" />
      <br />
      <img style="border:1px solid red; width:100%;" src="../assets/images/demo-logo.png" width="150" />
   </body>
</html>

The -moz-opacity Property

The -moz-opacity property of an image is used to set the opacity of an image. This property is used to create a transparent image in Mozilla. IE uses filter:alphaopacity = x to create transparent images.

In Mozilla -moz-opacity: x, x can be a value from 0.0 - 1.0. A lower value makes the element more transparent. The same thing goes for the CSS3 - valid syntax is opacity: x.

In IE filter: alpha(opacity=x), x can be a value from 0 - 100. A lower value makes the element more transparent.

Example

HTML/CSS 
<!DOCTYPE html>
<html>
   <body>
      <img style="border:1px solid red;-moz-opacity:0.4;filter:alpha(opacity=40);"
src="../assets/images/demo-logo.png" width="150" />
   </body>
</html>

Practical Examples

Creating a foolproof responsive image class and a circular profile avatar modifier:

CSS
<style>
/* 1. Make all images responsive by default */
img {
   max-width: 100%;
   height: auto;
   display: block; /* Removes weird bottom spacing */
}

/* 2. Create a circular avatar class */
.avatar-circle {
   width: 150px;
   height: 150px;
   border-radius: 50%;
   object-fit: cover; /* Prevents stretching if image isn't a perfect square */
}
</style>

<img class="avatar-circle" src="../assets/images/demo-photo.jpg" alt="Avatar">

Clipping & Masking

The clip-path property allows you to cut an element down to a defined shape, hiding everything outside its boundaries. This gives you powerful control over what part of an image or element is visible, enabling complex geometric designs without an image editor.

CSS 
img {
  clip-path: circle(50%);
}

Common Mistakes

  • Not setting max-width: 100% − If an image is 1200px wide but viewed on a 400px phone screen, it will blow out the layout and create horizontal scrolling.
  • Forgetting height: auto − If you set max-width: 100% but hardcode a height attribute in the HTML, the image will squish and distort. height: auto preserves the aspect ratio.
  • Baking borders/shadows into the image file − Using Photoshop to add a drop shadow to an image. If the site theme changes, the image is ruined. Always use CSS box-shadow and border on the image element instead.

Best Practices

  • Global Responsive Rule − Add img { max-width: 100%; height: auto; } to your base CSS reset to ensure no image ever breaks out of its container.
  • Always include the alt attribute − While technically an HTML requirement, missing alt tags can mess up layout alignment if the image fails to load. More importantly, the alt text is essential for screen readers to describe the image to visually impaired users.
  • Use object-fit: cover for fixed dimensions − If you must force an image into a specific box size (like a square grid), use object-fit: cover to crop it beautifully without distorting the pixels.

Interview Questions

Q: How do you make an image responsive in CSS?

A: By applying max-width: 100%; and height: auto;. This allows the image to scale down to fit its container without stretching.

Q: What does the object-fit property do?

A: It dictates how an <img> or <video> should be resized to fit its container. cover fills the box by cropping, while contain fits it inside entirely.

Q: Why is there often a small gap (few pixels) directly below an <img> tag, and how do you remove it?

A: Images are inline elements by default, so they sit on the text baseline, leaving space for descenders (like the tail of a "y"). Fix it by setting display: block; on the image.

Q: How do you create a perfect circle from a square image?

A: Apply border-radius: 50%; to the image.

Summary

Images are the heaviest visual elements on most websites. Ensuring they behave responsively (never exceeding their container width) and maintain their aspect ratios is critical. Modern properties like object-fit give developers Photoshop-like cropping control directly in the browser.

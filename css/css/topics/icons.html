Topic 18

CSS Icons

Icons in modern CSS are typically added via icon libraries rather than raw image files. You insert a small <i> or <span> tag with a specific class name, and the library's CSS or font renders the icon.

Because they are scalable vectors, you can easily resize and recolor them using plain CSS properties like font-size and color.

Font Awesome

To use Font Awesome, include their script kit link in the <head>. Then, add classes to an <i> tag.

HTML/CSS
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css">
</head>
<body>
  <i class="fas fa-cloud"></i>
  <i class="fas fa-heart"></i>
  <i class="fas fa-car"></i>
</body>
</html>

Bootstrap Icons

You can include Bootstrap Icons via a CDN <link> stylesheet and use the bi classes.

HTML/CSS
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">
</head>
<body>
  <i class="bi bi-alarm"></i>
  <i class="bi bi-apple"></i>
</body>
</html>

Google Material Icons

Include the Google Fonts stylesheet. Unlike others, the icon name goes inside the tag as text.

HTML/CSS
<!DOCTYPE html>
<html>
<head>
  <link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
</head>
<body>
  <i class="material-icons">favorite</i>
  <i class="material-icons">thumb_up</i>
</body>
</html>

Styling Icons with CSS

Once an icon is added to the page, it acts like normal text. You can change its size, color, and add interactive effects.

HTML/CSS
<!DOCTYPE html>
<html>
<head>
  <link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
  <style>
    .styled-icon {
      font-size: 48px;
      color: #3b82f6;
      transition: color 0.3s, transform 0.3s;
      cursor: pointer;
    }
    .styled-icon:hover {
      color: #ef4444;
      transform: scale(1.2);
    }
  </style>
</head>
<body>
  <i class="material-icons styled-icon">star</i>
</body>
</html>

Practical Examples

Old vs New Way: Replacing traditional raster images with modern font icons for UI buttons.

HTML/CSS
<!DOCTYPE html>
<html>
<head>
  <link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
  <style>
    .btn { display: inline-flex; align-items: center; gap: 8px; padding: 10px 20px; background: #eee; border: none; border-radius: 4px; font-size: 16px; }
    .icon-img { width: 24px; height: 24px; }
  </style>
</head>
<body>
  <p>Old Way (Using an image):</p>
  <button class="btn"><img src="../assets/images/demo-icon.png" class="icon-img" alt="Icon"> Save</button>
  <br><br>
  <p>New Way (Using a font icon):</p>
  <button class="btn"><i class="material-icons">save</i> Save</button>
</body>
</html>

Common Mistakes

  • Using images for small UI icons − Raster images (PNG/JPG) pixelate on high-DPI screens when resized, and require multiple files for different colors. Icon fonts solve this by being scalable vector text.
  • Forgetting to link the library − If your <i> tags are rendering as empty spaces or blank squares, you likely forgot to include the CDN <link> or <script> tag in the head.

Best Practices

  • Use semantic tags or aria attributes − While <i> is historically common, for accessibility it's good to add aria-hidden="true" to decorative icons so screen readers skip them.
  • Pick one library − Loading Font Awesome, Bootstrap Icons, AND Material Icons on the same site will bloat your page load time. Pick one and stick with it.
  • Ensure accessibility − Icon-only buttons or links need an aria-label or visually-hidden text, since screen readers cannot interpret an icon glyph alone.

Interview Questions

Q: How do you change the color and size of a font icon?

A: Because font icons are treated as text characters by the browser, you simply use the standard CSS color and font-size properties.

Q: What is the main advantage of an icon font over an image sprite?

A: Icon fonts are vector-based, meaning they can scale to any size without losing quality, and they can be styled dynamically with CSS (e.g., hover states) without needing additional image files.

Summary

Icon libraries like Font Awesome, Bootstrap Icons, and Material Icons are the standard way to add vector icons to web projects. By treating icons as text elements, you gain the full power of CSS typography tools to scale, color, and animate them seamlessly.

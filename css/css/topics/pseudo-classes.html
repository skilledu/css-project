Pseudo Classes

CSS pseudo-classes are used to add special effects to some selectors. You do not need to use JavaScript or any other script to use these classes. The syntax of pseudo-classes is:

CSS Syntax 
/* Basic pseudo-class syntax */
selector:pseudo-class { property: value; }

/* CSS classes combined with pseudo-classes */
selector.class:pseudo-class { property: value; }

Common Pseudo-Classes

Pseudo-Class Description
:linkApplies to unvisited links.
:visitedApplies to links that have been visited.
:hoverApplies when the mouse is placed over an element.
:activeApplies when the element is being activated (e.g., clicked).
:focusApplies when an element has keyboard focus.
:first-childApplies to an element that is the first child of its parent.
:langApplies based on the language setting of a document.

hover Pseudo-Class

The most popular use of pseudo-classes is to change the color of links when you hover over them.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         a:link    { color: #000000; }  /* Unvisited link */
         a:visited { color: #006600; }  /* Visited link */
         a:hover   { color: #FFCC00; }  /* Mouse over link */
         a:active  { color: #FF00CC; }  /* Selected link */
      </style>
   </head>
   <body>
      <a href="#">Bring Mouse Here</a>
   </body>
</html>

focus Pseudo-Class

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         a:focus { color: #0000FF; }
      </style>
   </head>
   <body>
      <a href="#">Click This Link</a>
   </body>
</html>

first-child Pseudo-Class

The :first-child pseudo-class matches a specified element that is the first child of another element and adds special style to it.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         div > p:first-child {
            text-indent: 25px;
         }
      </style>
   </head>
   <body>
      <div>
         <p>First paragraph in div. This will be indented.</p>
         <p>Second paragraph in div. This will NOT be indented.</p>
      </div>
   </body>
</html>

lang Pseudo-Class

The :lang pseudo-class allows constructing selectors based on the language setting of specific tags. This is useful in documents that must appeal to multiple languages.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         /* Quote styles for different languages */
         :lang(en) { quotes: '"' '"' "'" "'"; }
         :lang(fr) { quotes: "<<" ">>" "<" ">"; }
      </style>
   </head>
   <body>
      <p>..<q lang="fr">A French quote</q>..</p>
   </body>
</html>

Practical Examples

Enhancing a list with zebra striping and providing accessible focus states for keyboard users:

CSS
<style>
/* Zebra Striping using structural pseudo-classes */
li:nth-child(even) {
   background-color: #f3f4f6;
}

/* Highlighting the very first item */
li:first-child {
   font-weight: bold;
   border-top: 2px solid blue;
}

/* Modern Accessibility: Show outline only for keyboard focus, not mouse clicks */
button:focus-visible {
   outline: 3px solid #3b82f6;
}
</style>

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
<button>Click to focus (or use Tab)</button>

Common Mistakes

  • Removing focus outlines blindly − Using *:focus { outline: none; }. This makes the website completely unusable for users navigating with the Tab key. Never remove a focus ring without replacing it with a custom visible style.
  • Using hover effects on mobile − Mobile devices don't have a hover state. Tap interactions often trigger :hover and it gets "stuck" until the user taps elsewhere, creating a confusing UI.
  • Misunderstanding nth-child vs nth-of-type − :nth-child(2) selects the 2nd child of a parent, regardless of what tag it is. :nth-of-type(2) selects the 2nd child that matches a specific tag type.

Best Practices

  • Use :focus-visible − This modern pseudo-class solves the "ugly focus ring on click" problem. It only shows the outline when the browser detects keyboard navigation, hiding it for mouse users.
  • Pair :hover with :focus − Whenever you add a hover effect to a button or link, apply the same effect to the focus state (e.g., a:hover, a:focus) to ensure keyboard users get the same visual feedback.
  • Pair Hover and Focus − Always provide a :focus style when you provide a :hover style for accessibility. The :focus state applies when a form element (input, textarea, button, link) is actively selected or tabbed into. Removing the default focus outline without providing a visible replacement makes it impossible for keyboard-only users to see where they are on the page. For example:
    input:focus {
  outline: 2px solid #1a73e8;
}

Interview Questions

Q: What is the difference between a pseudo-class and a pseudo-element?

A: A pseudo-class (:hover) targets the STATE of an existing element. A pseudo-element (::before) actually injects new virtual content into the DOM.

Q: How does :nth-child(2n) work?

A: The n acts as a counter starting from 0. It selects every 2nd element (2*0=0, 2*1=2, 2*2=4, etc.). It is identical to :nth-child(even).

Q: What does the :not() pseudo-class do?

A: It is an exclusion selector. For example, div:not(.hidden) selects all divs EXCEPT those that have the class hidden.

Summary

Pseudo-classes allow you to style elements based on user interaction (like hovering or focusing) or their structural position in the DOM (like the first or last child). They are essential for creating dynamic, interactive, and accessible user interfaces without writing complex JavaScript event listeners.

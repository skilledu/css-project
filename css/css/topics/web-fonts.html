Web Fonts

Web Fonts allows you to use fonts that are not installed on the user's computer.

You can use the @font-face rule to define a Web Font. When you have found or bought the font you wish to use, just include the font file on your web server, and it will be automatically downloaded to the user when needed.

Different web fonts formats

FormatExtensionDescription
TrueType Fonts.ttfDeveloped by Apple and Microsoft. Very common font format for both Mac and Windows operating systems.
OpenType Fonts.otfBuilt on TrueType, developed by Microsoft and Adobe. Scalable computer font format.
Web Open Font Format.woffFont format for use in web pages, essentially TrueType/OpenType with compression.
WOFF 2.0.woff2Provides better compression than WOFF 1.0.
SVG Fonts.svg / .svgzUse SVG elements to define glyphs. Excellent for mobile devices.
Embedded OpenType.eotCompact form of OpenType designed by Microsoft for use as embedded fonts.

Defining a Web Font

To use a web font, you define it with the @font-face rule and then apply it via font-family.

CSS 
@font-face {
   font-family: myFirstFont;
   src: url(https://fonts.gstatic.com/s/roboto/v30/KFOmCnqEu92Fr1Mu4mxKKTU1Kg.woff2);
}
div {
   font-family: myFirstFont;
}

Practical Examples

Declaring a custom local font using @font-face and applying it to the document with modern performance best practices:

CSS
<style>
/* Define the custom font */
@font-face {
   font-family: "MyCustomFont";
   src: url("https://fonts.gstatic.com/s/opensans/v34/memvYaGs126MiZpBA-UvWbX2vVnXBbObj2OVTS-mu0SC55I.woff2") format("woff2");
   font-weight: 400;
   font-style: normal;

   /* Crucial for performance: prevents invisible text while loading */
   font-display: swap;
}

body {
   /* Apply the font with a safe generic fallback */
   font-family: "MyCustomFont", sans-serif;
}
</style>

<div>
  <h1>Custom Font Heading</h1>
  <p>Custom font text.</p>
</div>

Common Mistakes

  • Using heavy, unoptimized font formats − Loading massive .ttf or .otf files directly. Always convert your web fonts to the highly compressed .woff2 format to drastically improve page speed.
  • Forgetting font-display: swap − By default, browsers hide text entirely until the custom font finishes downloading (Flash of Invisible Text). Adding font-display: swap forces the browser to show the fallback font immediately, swapping in the custom font once it loads. This ensures text remains visible and readable while a custom web font loads.
  • Loading unused font weights − Importing 100, 200, 300, 400, 500, 600, 700, 800, and 900 weights from Google Fonts when your design only actually uses 400 and 700.

Best Practices

  • Preload Critical Fonts − If a custom font is used for your main headings above the fold, add <link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin> in your HTML <head> to download it instantly.
  • Limit Font Families − Every new font family adds HTTP requests and rendering time. Stick to a maximum of 2 custom web font families per site.

Interview Questions

Q: What is the preferred file format for web fonts today?

A: WOFF2 (Web Open Font Format 2). It offers the best compression algorithms specifically designed for the web, resulting in the smallest file sizes.

Q: What does the font-display: swap property do?

A: It instructs the browser to immediately render text using the system fallback font, and then "swap" the custom font in as soon as it finishes downloading, preventing invisible text delays.

Q: How do you serve different styles (like italic or bold) of the same font?

A: You write multiple @font-face rules that share the exact same font-family name, but define different font-weight or font-style values, pointing to their respective font files.

Summary

Web Fonts break developers free from the limited pool of "web-safe" system fonts. By utilizing the @font-face rule and sticking to highly compressed .woff2 formats, you can deliver stunning typography without crippling your website's load time.

Topic 19

Links

We will revisit the same properties when we will discuss Pseudo-Classes of CSS.

The :link signifies unvisited hyperlinks.

The :visited signifies visited hyperlinks.

The :hover signifies an element that currently has the user's mouse pointer hovering over it.

The :active signifies an element on which the user is currently clicking.

Usually, all these properties are kept in the header part of the HTML document.

Remember: a:hover MUST come after a:link and a:visited in the CSS definition in order to be effective. Also, a:active MUST come after a:hover in the CSS definition as follows:

a:link {color: #000000;}
a:visited {color: #006600;}
a:hover {color: #FFCC00;}
a:active {color: #FF00CC;}

Now, we will see how to use these properties to give different effects to hyperlinks.

Color of Links

The following example demonstrates how to set the link color. Possible values could be any color name in any valid format.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         a:link {color:#000000}
     </style>
   </head>
   <body>
      <a href="#">Link</a>
   </body>
</html>

Color of Visited Links

The following example demonstrates how to set the color of visited links. Possible values could be any color name in any valid format.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         a:visited {color: #006600}
      </style>
   </head>
   <body>
      <a href="#">Click this link</a>
   </body>
</html>

It will produce the following link. Once you will click this link, it will change its color to green.

Color of Links when Mouse is Over

The following example demonstrates how to change the color of links when we bring a mouse pointer over that link. Possible values could be any color name in any valid format.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         a:hover {color: #FFCC00}
      </style>
   </head>
   <body>
      <a href="#">Link</a>
   </body>
</html>

It will produce the following link. Now, you bring your mouse over this link and you will see that it changes its color to yellow.

Practical Examples

Styling a link with distinct visual feedback for hover and focus states, adhering strictly to the LVHA cascade order:

CSS
<style>
/* 1. Link (Unvisited) */
a:link {
   color: #3b82f6;
   text-decoration: underline;
}

/* 2. Visited */
a:visited {
   color: #6366f1; /* Slightly different color for visited state */
}

/* 3. Hover & Focus (Accessibility) */
a:hover,
a:focus {
   color: #1d4ed8;
   text-decoration: none; /* Provide clear feedback by removing underline */
}

/* 4. Active (While clicking) */
a:active {
   color: #1e3a8a;
}
</style>

<a href="#" class="nav-link">Hover over me!</a>

Common Mistakes

  • Writing pseudo-classes in the wrong order − Putting :hover before :visited. Because of the cascade, if the link is visited, the visited style will permanently override the hover style.
  • Removing focus outlines − Writing a:focus { outline: none; } without providing alternative styling. This completely destroys the site for users navigating with a keyboard.
  • Relying entirely on color − Removing underlines from links in paragraph text and relying only on a slightly different color. Colorblind users will not know it's a link.

Best Practices

  • Follow the LVHA Order − Always declare link states in this exact order: Link, Visited, Hover, Active. (Mnemonic: LoVe? HA!).
  • Provide Visual Feedback − Links should react when a user hovers over them. Changing color, swapping underlines, or adding slight transitions makes the site feel alive and usable.
  • Preserve Accessibility − Never remove underlines from links within blocks of text, and ensure the :focus state is clearly visible for keyboard navigators.
  • Preserve accessibility − Removing default link underlines and color cues can make links hard to distinguish from plain text for some users. Always ensure links stand out clearly from surrounding content.

Interview Questions

Q: What is the correct order to define CSS link pseudo-classes?

A: Link, Visited, Hover, Active (LVHA).

Q: Why is the LVHA order strictly necessary?

A: Because these pseudo-classes share the exact same specificity weight. Therefore, the cascade resolves conflicts purely based on source order. If :hover comes before :visited, a visited link will never show its hover state.

Q: What does the :focus pseudo-class target?

A: It targets an element when it receives focus, typically by the user tabbing through the page with a keyboard.

Q: Can you style a :visited link to have a different font-size?

A: No. For security and privacy reasons (to prevent sites from sniffing your browsing history), browsers heavily restrict what can be styled with :visited. You can generally only change the color.

Summary

Links are the interactive connective tissue of the web. Proper link styling goes beyond just changing colors—it requires strict adherence to the LVHA cascade order to ensure states don't override each other. By providing clear visual feedback on hover and preserving accessibility outlines, you ensure a superior user experience.

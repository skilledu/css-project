Pseudo Elements

CSS pseudo-elements are used to add special effects to some selectors. You do not need to use JavaScript or any other script to use those effects. A simple syntax of pseudo-element is as follows:

CSS Syntax
selector:pseudo-element {property: value}

CSS classes can also be combined with pseudo-elements:

CSS Syntax
selector.class:pseudo-element {property: value}

The most commonly used pseudo-elements are as follows:

Pseudo-Element Description
:first-lineAdds special styles to the first line of the text in a selector.
:first-letterAdds special style to the first letter of the text in a selector.
:beforeInserts some content before an element.
:afterInserts some content after an element.

first-line pseudo-element

The following example demonstrates how to use the ::first-line element to add special effects to the first line of elements in the document.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         p:first-line { text-decoration: underline; }
         p.noline:first-line { text-decoration: none; }
      </style>
   </head>
   <body>
      <p class="normal">This line would not have any underline because this belongs to normal class.</p>
      <p>The first line of this paragraph will be underlined as defined in the CSS rule
above. Rest of the lines in this paragraph will remain normal. This example shows how to
use :first-line pseudo element to give effect to the first line of any HTML element.</p>
   </body>
</html>

first-letter pseudo-element

The following example demonstrates how to use the ::first-letter element to add special effects to the first letter of elements in the document.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         p:first-letter { font-size: 5em; }
         p.normal:first-letter { font-size: 10px; }
      </style>
   </head>
   <body>
      <p class="normal">First character of this paragraph will be normal and will have font size 10px;</p>
      <p>The first character of this paragraph will be 5em big  as  defined in the CSS
rule above. Rest of the characters in this paragraph will remain normal. This example
shows how to use :first-letter pseudo element to give effect to the first characters  of
any HTML element.</p>
   </body>
</html>

before pseudo-element

The following example demonstrates how to use the ::before element to add some content before any element.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         p::before {
            content: "🔥 ";
         }
      </style>
   </head>
   <body>
      <p>This line will be preceded by a fire emoji.</p>
      <p>This line will also be preceded by a fire emoji.</p>
      <p>Pseudo-elements make adding icons easy!</p>
   </body>
</html>

after pseudo-element

The following example demonstrates how to use the ::after element to add some content after any element.

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style type="text/css">
         .new-item::after {
            content: " New!";
            color: white;
            background-color: red;
            font-size: 10px;
            padding: 2px 5px;
            margin-left: 5px;
            border-radius: 3px;
         }
      </style>
   </head>
   <body>
      <p>Regular Item</p>
      <p class="new-item">Special Limited Item</p>
   </body>
</html>

Practical Examples

Injecting decorative quotation marks around a blockquote purely via CSS, keeping the HTML semantic and clean:

CSS
<style>
blockquote {
   position: relative;
   padding: 20px 40px;
}

blockquote::before {
   content: "“"; /* Injecting the opening quote */
   position: absolute;
   left: 10px;
   top: -10px;
   font-size: 4rem;
   color: #ccc;
}

blockquote::after {
   content: "”"; /* Injecting the closing quote */
   /* Position logic goes here */
}
</style>

Common Mistakes

  • Forgetting the content property − ::before and ::after will not render at all unless you include the content property. Even if it is empty, you must declare content: "";.
  • Using them for critical content − Injecting important text or images via pseudo-elements is bad for SEO and screen readers. They should be used strictly for decorative flourishes.
  • Using single colons (:before) − While older browsers supported single colons, the modern CSS3 standard requires double colons (::) to clearly distinguish pseudo-elements from pseudo-classes.

Best Practices

  • Use for purely visual elements − Use pseudo-elements for custom bullet points, custom checkboxes, quotation marks, or gradient overlays. This keeps your HTML DOM lean and semantic.
  • Display block − By default, ::before and ::after render as inline elements. If you want to give them width/height, you must set them to display: block or inline-block (unless they are absolutely positioned).
  • Keep essential content in HTML − Content inserted via ::before and ::after with the content: property is often invisible to screen readers. It should only be used for decorative elements, not essential information.

Interview Questions

Q: Why is the content property mandatory for ::before and ::after?

A: Because pseudo-elements are virtually injected into the DOM. Without the content property, the browser assumes there is nothing to inject, so the element is never generated.

Q: Can you interact with pseudo-elements using JavaScript?

A: Not directly. Because they are not part of the actual HTML DOM (they only exist in the CSS rendering tree), you cannot attach event listeners (like clicks) directly to a pseudo-element.

Q: What does the ::selection pseudo-element do?

A: It allows you to style the background color and text color of the text that a user highlights/selects with their mouse.

Summary

Pseudo-elements act like virtual HTML tags created entirely within CSS. They allow you to add decorative content, icons, and complex stylistic overlays to elements without bloating your actual HTML markup. Always remember the double colon syntax and the mandatory content property.

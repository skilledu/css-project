Topic 20

Lists

Lists are very helpful in conveying a set of either numbered or bulleted points. This chapter teaches you how to control list type, position, style, etc., using CSS.

We have the following CSS properties, which can be used to control lists:

PropertyDescription
list-style-typeallows you to control the shape or appearance of the marker.
list-style-positionspecifies whether a long point that wraps to a second line should align with the first line or start underneath the start of the marker.
list-style-imagespecifies an image for the marker rather than a bullet point or number.
list-styleserves as shorthand for the preceding properties.
marker-offsetspecifies the distance between a marker and the text in the list.

The list-style-type Property

The list-style-type property allows you to control the shape or style of bullet point (also known as a marker) in the case of unordered lists and the style of numbering characters in ordered lists.

Unordered List Values

ValueDescription
noneNA (Removes the marker)
discA filled-in circle (default)
circleAn empty circle
squareA filled-in square

Ordered List Values

ValueDescriptionExample
decimalNumber1, 2, 3, 4, 5
decimal-leading-zero0 before the number01, 02, 03, 04, 05
lower-alphaLowercase alphanumeric charactersa, b, c, d, e
upper-alphaUppercase alphanumeric charactersA, B, C, D, E
lower-romanLowercase Roman numeralsi, ii, iii, iv, v
upper-romanUppercase Roman numeralsI, II, III, IV, V
lower-greekThe marker is lower-greekalpha, beta, gamma

Example

HTML/CSS 
<!DOCTYPE html>
<html>
   <head>
      <style>
         ul { list-style-type: square; }
         ol { list-style-type: upper-alpha; }
         ol.roman { list-style-type: lower-roman; }
      </style>
   </head>
   <body>
      <h3>Unordered List</h3>
      <ul>
         <li>Square Item 1</li>
         <li>Square Item 2</li>
      </ul>

      <h3>Ordered List</h3>
      <ol>
         <li>First item (A)</li>
         <li>Second item (B)</li>
      </ol>

      <ol class="roman">
         <li>First roman item (i)</li>
         <li>Second roman item (ii)</li>
      </ol>
   </body>
</html>

Practical Examples

Styling a list to remove default browser styling, and replacing the bullets with a custom SVG icon using the ::before pseudo-element (which offers better alignment control than list-style-image):

CSS
<style>
.custom-list {
   list-style: none; /* Remove default bullets */
   padding: 0;       /* Remove default indentation */
}

.custom-list li {
   position: relative;
   padding-left: 30px;
   margin-bottom: 10px;
}

.custom-list li::before {
   content: "✓";
   position: absolute;
   left: 0;
   color: #10b981; /* Green checkmark */
   font-weight: bold;
}
</style>

<ul class="custom-list">
  <li>First custom item</li>
  <li>Second custom item</li>
</ul>

Common Mistakes

  • Removing padding without replacing it − Browsers add default left-padding to <ul> to make room for bullets. If you set padding: 0; but keep list-style-type: disc, the bullets will render outside the screen edge.
  • Using list-style-position: inside carelessly − If a list item wraps to a second line, inside causes the text to wrap directly under the bullet point rather than aligning cleanly with the text above it.
  • Using list-style-image for complex icons − This property is notoriously difficult to position vertically. Using a background image or a pseudo-element is much easier to align.

Best Practices

  • Reset lists when used for layout − If you are using a <ul> for a navigation bar, immediately apply list-style: none; and padding: 0; to reset it to a clean slate.
  • Prefer pseudo-elements for custom bullets − As shown in the practical example, ::before gives you pixel-perfect control over the size, color, and vertical alignment of custom bullet icons.

Interview Questions

Q: How do you completely remove the bullets from an unordered list?

A: Apply list-style: none; or list-style-type: none;.

Q: What is the difference between list-style-position: inside and outside?

A: outside (the default) places the bullet outside the text flow, so multi-line text aligns perfectly. inside brings the bullet into the text block, meaning wrapped text will sit directly underneath the bullet.

Q: Can you style the default bullet color without changing the text color?

A: Yes, in modern CSS you can use the ::marker pseudo-element (e.g., li::marker { color: red; }) to style the bullet independently.

Summary

While lists are simple by nature, they form the structural backbone of navigation menus and feature sets. Understanding how to reset their default padding, control bullet positioning, and inject custom icons via pseudo-elements allows you to transform boring lists into engaging UI components.
